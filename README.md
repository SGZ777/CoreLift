# CoreLift – Dashboard (React + Vite + Bootstrap)

    npm install
    npm run dev

Os dados ficam em `public/registros.json` (formato compacto em arrays).
Para usar uma API, defina `VITE_API_URL` em `.env` — ela pode devolver o mesmo formato
ou objetos `{ ts, tipo, turno, status, temp, vib, rot, cor, horas, diasManut, efic, conf }`.
